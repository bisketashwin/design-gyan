# Preproduction: 

**Human Tasks**
Study games factors: statergy, fun factors, psyuchology, achivement.
Study Art, animation, vfx, sound and music. how they reinforce and enhance games factors.
Study Game mechanics, rules, level design, story telling.

**AI Helpers**
Feed all your learnings into AI. And gget it formated and crisped up. 

**Human task**
Filter modify AI output till it meets tyour expectation. Make analysis presnetations.

---

# Ideation: 

**Human Tasks**
Brainstorming, find art, animation, music inspirations. Create Moodbard or concept board.

**AI Helpers**
Feed all mood boads one by one into AI. Genearate Draft Art, animation and music.

**Human task**
SHare it with team and players. Re prompt the AI and get variations. Create Final Moodboards.

---

# Production

**Human Tasks**
**Game Design:** Define game core loop, game mechanics, game rules, game story.
**Art & Sound design:** Defile all the charecters and assets required.
**Game Development:** Define game engine, game architecture, game logic, game physics, game AI.

**AI Helpers**
Create assets, program the game logic, write game code.

**Human task**
Refine Assets produced by AI. Test the Game evaluate user flow and User experience. Interate with AI.
